## Forks

Forks and modified versions must use a different name and branding.

A fork may state that it is based on Spectra, but it must not present itself as Spectra, official Spectra, or a MOZAGA FOUNDATION product.

Forks intended for distribution should replace Spectra logos, app icons, splash screens, app identifiers, package names, endpoint defaults, and app-store metadata before release.
